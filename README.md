# MarketPro — Sistema de Gestão para Supermercados (Angular)

**Disciplina:** Desenvolvimento Web Front-End (Universidade FUMEC)  
**Professor:** Dângelo Silva Miranda  

## 🚀 Tecnologias Utilizadas
- **Framework:** Angular v16+
- **Linguagem:** TypeScript
- **Estilização:** CSS3 / HTML5 Responsivo
- **Navegação:** Angular Router com routerLink e rotas dinâmicas
- **Gestão de Dados:** RxJS (BehaviorSubject) & Services com Mock Objects

## 📦 Como Executar o Projeto
1. Instale as dependências:
   ```bash
   npm install
   ```
2. Execute o servidor de desenvolvimento:
   ```bash
   ng serve
   ```
3. Abra o navegador em: `http://localhost:4200/`
