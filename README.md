# MarketPro - Atualizado (Botão no Canto Removido & URL da Imagem Ocultada)

Projeto Angular 15 integrado com JSON Server e Chart.js.

## Alterações Desta Versão:
1. Removido o botão `+ Novo Produto (CRUD)` do cabeçalho superior direito da tela Admin, mantendo apenas o botão `+ Adicionar Produto` na área da tabela.
2. Ocultado o campo de texto de URL da Imagem no formulário de produto, mantendo os seletores interativos de imagens de categoria com pré-visualização.

## Como Executar

1. Extraia os arquivos.
2. No terminal: `npm install`
3. Em uma janela de terminal: `npm run backend`
4. Em outra janela de terminal: `npm start`
5. Abra o navegador em `http://localhost:4200`
