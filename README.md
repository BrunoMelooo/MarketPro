# MarketPro - Sistema Integrado de Vendas e Estoque

Projeto Angular 15 integrado com JSON Server, Chart.js e arquitetura de `environments` para separação de desenvolvimento e produção.

## Como Executar
1. Extraia os arquivos.
2. No terminal: `npm install`
3. Em uma janela de terminal: `npm run backend`
4. Em outra janela de terminal: `npm start`
5. Abra o navegador em `http://localhost:4200`

## Funcionalidades
- **Loja Virtual (`/loja`)**: Catálogo com busca, filtros por categoria e carrinho integrado com baixa automática de estoque.
- **Gestão Interna (`/gestao-interna`)**: Acesso discreto pelo rodapé ("Portal do Colaborador"), dashboard analítico e edição rápida de estoque por produto.
